Sobre mim

Estudo Ciência da Computação na UDF, em Brasília. Comecei com Python e C e hoje também faço sites com HTML, CSS, JavaScript e Bootstrap e modelo bancos de dados em MySQL.

Um exemplo do que já construí é o Steam Price Tracker: um script em Python que consulta a API da Steam, guarda o histórico de preços em JSON e avisa pelo Telegram quando um jogo muda de preço. Ele roda agendado no GitHub Actions, sem eu precisar fazer nada.

Meu foco é o desenvolvimento full stack. No momento estudo Java, Node.js, React, Angular e MongoDB, e busco um estágio onde eu possa aprender com um time e colocar tudo isso em prática.

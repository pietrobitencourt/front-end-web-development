## Português (BR)

### Sobre o repositório

Este repositório reúne as atividades práticas que desenvolvo na disciplina de **Desenvolvimento Front-End para Web**. Cada atividade fica em uma pasta própria, numerada na ordem em que foi feita, com seu próprio README e seus prints, e pode ser aberta direto no navegador, sem etapa de build.

O objetivo é documentar minha evolução, desde HTML e CSS puros até o uso de bibliotecas e novas ferramentas, mantendo cada projeto organizado e fácil de executar. O repositório continua crescendo: novas atividades entram em pastas numeradas (`06-...`, `07-...`) conforme a disciplina avança.

### O que cada atividade pratica

**01 · PetShop Taguatinga**
- Estrutura semântica com `header`, `nav`, `main`, `section` e `footer`
- Layout com Flexbox e unidades relativas (`rem`, `vh`)
- Header fixo, navegação por âncoras e transições (`transition`, `transform`) em hover
- Imagens com `object-fit`, mapa incorporado via `iframe` e formulário de contato

**02 · Picos do Brasil**
- Evolução do projeto 01: novo item de menu, nova seção e troca completa da paleta de cores
- Conteúdo sobre o Brasil organizado em colunas (Flexbox), com altitude e localização de cada pico
- Galeria de fotos, mapa do Google My Maps incorporado e formulário de contato

**03 · Recanto News**
- Sistema de grid do Bootstrap (`container`, `row`, `col-lg-*`)
- Componentes: navbar com menu colapsável e dropdown, carrossel, cards e accordion
- Ícones com Font Awesome
- Tema escuro da navbar com `data-bs-theme`

**04 · Dia Mundial dos Animais**
- Dez componentes do Bootstrap: navbar, dropdown, carousel, card, accordion, alert, modal, toast, list group e badge
- Interatividade com JavaScript: toast exibido por botão com `bootstrap.Toast`
- Paleta personalizada com variáveis CSS, sobrescrevendo as variáveis `--bs-*` do Bootstrap
- Navbar fixa (`sticky-top`) com navegação por âncoras e `scroll-margin-top`
- Cards de mesma altura, imagens com `object-fit` e carrosséis com indicadores e legendas
- Acessibilidade: textos `alt` descritivos, `aria-label` e `visually-hidden`

**05 · Portfólio Pessoal**
- Arquitetura com pastas separadas (`css/`, `js/`, `img/`, `docs/`) e design responsivo *mobile first*
- Dados separados da interface: lista de projetos em `projetos.js` e cards gerados com JavaScript (`map`, *template literals*, `innerHTML`)
- Filtro por tecnologia com `filter` e `includes`, usando delegação de eventos
- Modal do Bootstrap preenchido por JavaScript, ScrollSpy e menu colapsável que fecha sozinho
- Variáveis CSS, `clamp()`, Grid e Flexbox, sobrescrevendo as variáveis `--bs-*` do Bootstrap
- Acessibilidade: link para pular o conteúdo, foco visível, `aria-pressed`, `aria-live` e `prefers-reduced-motion`

### Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/pietrobitencourt/front-end-web-development.git
   ```
2. Entre na pasta da atividade desejada, por exemplo:
   ```bash
   cd front-end-web-development/05-portfolio
   ```
3. Abra o `index.html` no navegador (ou use a extensão **Live Server** do VS Code).

Não é necessário instalar nada: as dependências das atividades 03 e 04 já estão incluídas na pasta do projeto. A atividade 05 carrega o Bootstrap e as fontes por CDN, então precisa de conexão com a internet para aparecer completa.

### What each project practices

**01 · PetShop Taguatinga**
- Semantic structure with `header`, `nav`, `main`, `section` and `footer`
- Flexbox layout and relative units (`rem`, `vh`)
- Fixed header, anchor navigation and hover transitions (`transition`, `transform`)
- Images with `object-fit`, an embedded map via `iframe` and a contact form

**02 · Picos do Brasil**
- Builds on project 01: a new menu item, a new section and a complete color palette change
- Content about Brazil laid out in Flexbox columns, with altitude and location for each peak
- Photo gallery, embedded Google My Maps and a contact form

**03 · Recanto News**
- Bootstrap grid system (`container`, `row`, `col-lg-*`)
- Components: collapsible navbar with dropdown, carousel, cards and accordion
- Icons with Font Awesome
- Dark navbar theme using `data-bs-theme`

**04 · World Animal Day**
- Ten Bootstrap components: navbar, dropdown, carousel, card, accordion, alert, modal, toast, list group and badge
- Interactivity with JavaScript: a toast shown by a button through `bootstrap.Toast`
- Custom palette using CSS variables, overriding Bootstrap's `--bs-*` variables
- Sticky navbar (`sticky-top`) with anchor navigation and `scroll-margin-top`
- Equal-height cards, images with `object-fit` and carousels with indicators and captions
- Accessibility: descriptive `alt` text, `aria-label` and `visually-hidden`

**05 · Personal Portfolio**
- Architecture with separate folders (`css/`, `js/`, `img/`, `docs/`) and mobile-first responsive design
- Data separated from the interface: the project list lives in `projetos.js` and the cards are generated with JavaScript (`map`, template literals, `innerHTML`)
- Technology filter with `filter` and `includes`, using event delegation
- Bootstrap modal filled by JavaScript, ScrollSpy and a collapsible menu that closes by itself
- CSS variables, `clamp()`, Grid and Flexbox, overriding Bootstrap's `--bs-*` variables
- Accessibility: skip link, visible focus, `aria-pressed`, `aria-live` and `prefers-reduced-motion`

### Getting started

1. Clone the repository:
   ```bash
   git clone https://github.com/pietrobitencourt/front-end-web-development.git
   ```
2. Enter the project folder you want, for example:
   ```bash
   cd front-end-web-development/05-portfolio
   ```
3. Open `index.html` in your browser (or use the VS Code **Live Server** extension).

Nothing needs to be installed: projects 03 and 04 already ship with their Bootstrap and Font Awesome files. Project 05 loads Bootstrap and the fonts from a CDN, so it needs an internet connection to display fully.
